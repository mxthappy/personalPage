这是你现在正在看的这个网站，也是我打磨最久的「作品」。

## 功能

- 博客 + 作品集 + 关于页，响应式布局
- 暗色科技主题：青紫渐变、毛玻璃卡片、微光效果
- 内容用 Markdown 管理，支持标签、目录、上一篇/下一篇
- RSS 订阅、Sitemap、SEO meta
- Giscus 评论 + Cloudflare Analytics 统计

## 技术亮点

- 使用 Astro Content Collections 做内容类型校验
- Tailwind CSS v4 CSS-first 主题配置
- 零前端框架依赖，全站静态生成，加载极快

## 部署

GitHub 仓库推送后由 Cloudflare Pages 自动构建部署，免费子域名，全程零运维。
